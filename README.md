# `mweb-crud` - MWeb Create, Read, Update, Delete
Helps to easily perform Create, Read, Update, & Delete operations for REST-API and server-side rendering data processing, and can generate OpenAPI.


<br/><br/><br/>
## Documentation

### Install and update using [pip](https://pip.pypa.io/en/stable/getting-started/):
```bash
pip install -U mweb-crud
```

<br/><br/>

**Please find [the Documentation](https://mweb.banglafighter.org/) with example from [hmtmcse.com/mweb](https://hmtmcse.com/mweb)**
