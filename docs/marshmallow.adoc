


== Time Field
```
dto.Time(allow_none=True, format="%H:%M:%S")
```

[cols="1,2,2", options="header"]
|===
|Format Code |Meaning           |Example

|%H          |Hour (00–23)      |14
|%I          |Hour (01–12)      |02
|%M          |Minute (00–59)    |30
|%S          |Second (00–59)    |45
|%p          |AM/PM             |PM
|===


== Date & DateTime Field
```
dto.Time(allow_none=True, format="%H:%M:%S")
```

[cols="1,2,2", options="header"]
|===
|Format Code |Meaning             |Example

|%Y          |4-digit year        |2025
|%m          |2-digit month       |07
|%d          |2-digit day         |11
|%H          |Hour (00–23)        |16
|%M          |Minute (00–59)      |30
|%S          |Second (00–59)      |00
|%f          |Microsecond         |123456
|%z          |UTC offset          |+0000
|%Z          |Time zone name      |UTC
|%A          |Weekday name        |Friday
|%a          |Short weekday       |Fri
|%B          |Month name          |July
|%b          |Short month name    |Jul
|===
